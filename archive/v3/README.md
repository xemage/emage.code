# v3 (archived layout)

The v3 **implementation** tree was promoted to the version-independent path
[`implementation/`](../../implementation/README.md) at the repository root.

v3 referred to the schema-first knowledge model (cookbooks, triggers, packaging,
registry). The current release stream (v4.0.0+) continues to use that model at
`implementation/` without a version prefix in the path.

For install instructions see [`README.md`](../../README.md#install) and
[`docs/releases/v4.0.0.md`](../../docs/releases/v4.0.0.md).
