## 1. How to read this register

- One row per finding id, or per group of ids that share a source, grade, status and disposition (the ids are listed one by one; a mechanical search for any id finds its row). The id is the source id; `TD-T671-*` ids are new rows created by this register, `K-*`, `SIGNOFF-*`, `CP38-*` and `P112-*` ids are the register's labels for items that had none.
- **Status**: `open`; `fixed` (with the commit or task and the evidence read on develop); `accepted` (a documented residual, or a decision of the user quoted verbatim); `obsolete`.
- **Disposition**: the plan-123 task that fixes it (T672 to T677, plus the T661 to T670 tasks where an item belongs to them), `fixed` (already closed), `accept`, `close as obsolete`, `new task needed` (what is said in the row), or a user action.
- **Brief**: `Y` means the id (or an unambiguous phrase for it) is named in the brief of the proposed task; `N` means the item sits in the same files but is **not** named in any brief, so the proposal is a scope extension of that task or a new task; `-` means not applicable (closed, accepted or context).
- **Grade** is the grade of the source (the `SECURITY:*` scale, `validation-gates` § Severity Definitions, the code-review levels, or the QA severity), unchanged. The register does not re-grade anything.
