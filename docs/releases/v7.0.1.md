## Highlights

Patch release: one real, user-reported bug fix, plus a root self-install harness refresh. No new
features, no behavior changes to any existing capability beyond the fix itself.

### Fixed

- **`@context-retriever` and `security-audit` MCP servers now actually work outside this repository**
  (T513). Both were structurally broken for every real downstream install — `scripts/install.sh`
  only ever copied platform config/knowledge projections, never the actual Python source
  (`implementation/runtime/memory/`, `implementation/runtime/security/`) these servers' commands
  import, so they could only ever have worked inside the emage.code source repo itself. Confirmed
  directly: a real downstream project (CWSO) had no `implementation/` directory at all. Fixed via a
  new `install_mcp_server_runtime()` step that copies both runtime directories into every target
  project on install and `--update`. Two further, real, independent gaps closed at the same time:
  neither server's declared Python dependency (the `mcp` SDK) was ever installed anywhere — install
  now prints an explicit, actionable one-time setup command instead of a generic client-side
  "Connection closed" error — and `@context-retriever` additionally needs a one-time, per-project
  search index built (also now clearly surfaced as a post-install step, since it can't be
  pre-built or shipped).

  **Action needed:** existing installs of `@context-retriever` or `security-audit` should run
  `--update` to receive the runtime source, then follow the two post-install notices install.sh now
  prints (one-time `pip install`, one-time index build) if they haven't already worked around this
  manually.

### Internal

- **Root self-install harness refresh to v7.0.0** (T512): propagated already-shipped v7.0.0
  `implementation/` content into this repository's own root self-install dogfooding mirrors across
  all 7 platforms, which had drifted stale. No behavior change for downstream users — this only
  affects this repository's own development environment.

## Breaking changes

None. This release is a pure bug fix plus internal housekeeping — no existing MCP server, platform
projection schema, or installer behavior changed for any user who was not already blocked by the
fixed bug. Confirmed via `node implementation/scripts/sync.mjs --check` (no drift across 577 files)
and the full test suite (`python3 tests/run.py`, 734 tests, 0 failures) at the time this release was
cut.
