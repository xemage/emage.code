# Release v5.0.0

## Install

Latest release: v5.0.0

**Recommended:** use the installer from a clone of this repository:

```bash
git clone https://gitlab.com/em-age/emage.code.git
cd emage.code
scripts/install.sh --target <your-project> --platform cursor
```

| Platform | `--platform` value |
|----------|-------------------|
| Cursor | `cursor` |
| GitHub Copilot (VS Code) | `github` |
| Gemini CLI | `gemini` |
| Opencode | `opencode` |
| Pi | `pi` |
| All platforms | `all` |

Makefile shortcut: `make install TARGET=<your-project> PLATFORM=cursor`

Configure MCP credentials from the generated platform config, then invoke:

```
/discover-skills "start new project"
/new-project "My SaaS application"
```

Full guide: [`implementation/README.md`](../../implementation/README.md)
and [Quick Start](../wiki/quick-start.md).

## Highlights

v5.0.0 promotes the schema-first implementation to a **version-independent**
repository layout and adds a one-command installer.

### Repository layout (breaking)

- **Current stream:** `implementation/` at repo root (was `v3/implementation/`)
- **Archived streams:** `archive/v1/`, `archive/v2/`, `archive/v3/` (pointer stub)
- CI, tests, sync, and validation gates updated for new paths

### Installer (new)

- `scripts/install.sh --target <dir> [--platform cursor|github|gemini|opencode|pi|all]`
- `make install TARGET=... PLATFORM=...`

### Documentation

- Updated `README.md`, `CONTRIBUTING.md`, wiki quick-start and implementation guide
- Release docs gate verifies `implementation/README.md`, `scripts/install.sh`, and wiki pages

## Breaking changes

- **Install path:** use `implementation/` or `scripts/install.sh` instead of `v3/implementation/`
- **v1/v2 trees:** moved to `archive/v1/` and `archive/v2/` (v2 CI drift gate unchanged)
- **Validation commands:** `--root implementation` from repository root
