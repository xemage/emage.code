# Release v6.0.1

## Install

Latest release: v6.0.1

**Recommended:** use the installer from a clone of this repository:

```bash
git clone https://gitlab.com/em-age/emage.code.git
cd emage.code
scripts/install.sh --target <your-project> --platform cursor
```

| Platform | `--platform` value |
|----------|-------------------|
| Cursor | `cursor` |
| GitHub Copilot (VS Code) | `github` |
| Gemini CLI | `gemini` |
| Opencode | `opencode` |
| Pi | `pi` |
| All platforms | `all` |

Makefile shortcut: `make install TARGET=<your-project> PLATFORM=cursor`

**Update an existing project** (requires `AGENTS.md` in the target):

```bash
scripts/install.sh --target <your-project> --platform cursor --update
```

Configure MCP credentials from the generated platform config, then invoke:

```
/discover-skills "start new project"
/new-project "My SaaS application"
```

Full guide: [`implementation/README.md`](../../implementation/README.md)
and [Quick Start](../wiki/quick-start.md).

## Highlights

v6.0.1 fixes installer behavior when target folders already exist and adds an
explicit update mode for refreshing an installed project.

### Installer fixes

- **Merge into existing dirs** — installing into an existing `.pi/`, `docs/`, or
  other platform folder no longer creates nested subfolders (e.g. `.pi/.pi`)
- **`--update` / `-u` flag** — sync platform trees to the latest release,
  removing stale generated files while preserving local workspace docs

### Tests

- Added `tests/functional/test_install_script.py` covering merge, update, and
  stale-file removal behavior

## Breaking changes

- None
