# Release v3.0.1

## Install

Latest release: v3.0.1

**v3 is the current release stream.** Copy the platform folder for your assistant
plus shared workspace files from `v3/implementation/`:

```bash
# GitHub Copilot (VS Code)
cp -r v3/implementation/.github         <your-project>/
mkdir -p <your-project>/.vscode
cp    v3/implementation/.vscode/mcp.json <your-project>/.vscode/

# Gemini CLI
cp -r v3/implementation/.gemini         <your-project>/

# Opencode
cp -r v3/implementation/.opencode       <your-project>/

# Cursor
cp -r v3/implementation/.cursor         <your-project>/

# Pi (terminal coding agent — https://pi.dev)
cp -r v3/implementation/.pi             <your-project>/.pi/

# Always include
cp    v3/implementation/AGENTS.md       <your-project>/
cp -r v3/implementation/docs            <your-project>/
```

Configure MCP credentials (`GITLAB_PERSONAL_ACCESS_TOKEN`, `BRAVE_API_KEY`, …)
from the generated platform config, then invoke:

```
/new-project "My SaaS application"
```

Full guide: [`v3/implementation/README.md`](../../v3/implementation/README.md)
and [Quick Start](../wiki/quick-start.md).

## Highlights

v3.0.1 is a documentation and packaging patch on top of v3.0.0.

### Release documentation contract

- Per-release briefs required at `docs/releases/vX.Y.Z.md` (Install + Highlights)
- GitLab Releases embed full install steps and feature highlights, not only merge commits
- Release job uses `GIT_DEPTH: "0"` for complete changelog history
- Template at `docs/releases/_template.md` for future releases

### Pi platform (v3-only)

- Manifest: `v3/implementation/platforms/pi.json`
- Generated output: `v3/implementation/.pi/` (agents, prompts, instructions, skills)
- Install docs aligned across README, wiki, and release briefs
- No v2 projection — avoids drift failures on the v2 sync path

### Ecosystem research

- Roadmap artifact: `docs/artifacts/research-agents-skills-ecosystem-v1.md`
- Inputs: Superpowers, Awesome OpenCode, Pi, HackerNoon skill patterns
