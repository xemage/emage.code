# Release v6.0.3

## Install

Latest release: v6.0.3

**Recommended:** use the installer from a clone of this repository:

```bash
git clone https://gitlab.com/em-age/emage.code.git
cd emage.code
scripts/install.sh --target <your-project> --platform cursor
```

| Platform | `--platform` value |
|----------|-------------------|
| Cursor | `cursor` |
| GitHub Copilot (VS Code) | `github` |
| Gemini CLI | `gemini` |
| Opencode | `opencode` |
| Pi | `pi` |
| All platforms | `all` |

Makefile shortcut: `make install TARGET=<your-project> PLATFORM=cursor`

**Update an existing project** (requires `AGENTS.md` in the target):

```bash
scripts/install.sh --target <your-project> --platform cursor --update
```

Configure MCP credentials from the generated platform config, then invoke:

```
/discover-skills "start new project"
/new-project "My SaaS application"
```

Full guide: [`implementation/README.md`](../../implementation/README.md)
and [Quick Start](../wiki/quick-start.md).

## Highlights

v6.0.3 improves test portability and adds session-archive documentation covering
repository history and upcoming Test-Driven Design planning.

### Test infrastructure

- **Bash path detection** — `test_install_script.py` now uses `shutil.which("bash")`
  via a `setUpClass` hook and skips gracefully when bash is absent, making the
  suite portable across CI environments where bash is not on `$PATH` by default.

### Documentation

- **Cursor chat archive** — three exported Cursor sessions added to
  `docs/archiv/cursor-chats/`: repository restructure/v3 history, skill
  discovery workflow, and the Superpowers plugin addition.
- **Optional TDD planning** — initial planning artifacts for the upcoming
  optional Test-Driven Design enforcement feature (v6.1.0 track):
  - `docs/artifacts/requirements-optional-tdd-v1.md`
  - `docs/plans/plan-008-optional-tdd-and-skill-gaps.md`
  - `docs/checkpoints/checkpoint-001-planning-tdd-skills.md`
