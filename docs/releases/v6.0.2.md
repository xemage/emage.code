# Release v6.0.2

## Install

Latest release: v6.0.2

**Recommended:** use the installer from a clone of this repository:

```bash
git clone https://gitlab.com/em-age/emage.code.git
cd emage.code
scripts/install.sh --target <your-project> --platform cursor
```

| Platform | `--platform` value |
|----------|-------------------|
| Cursor | `cursor` |
| GitHub Copilot (VS Code) | `github` |
| Gemini CLI | `gemini` |
| Opencode | `opencode` |
| Pi | `pi` |
| All platforms | `all` |

Makefile shortcut: `make install TARGET=<your-project> PLATFORM=cursor`

**Update an existing project** (requires `AGENTS.md` in the target):

```bash
scripts/install.sh --target <your-project> --platform cursor --update
```

On update, `docs/tasks/active-tasks.md` and `docs/tasks/completed-tasks.md` keep
their task rows; only headers and footers are refreshed from the template.

Configure MCP credentials from the generated platform config, then invoke:

```
/discover-skills "start new project"
/new-project "My SaaS application"
```

Full guide: [`implementation/README.md`](../../implementation/README.md)
and [Quick Start](../wiki/quick-start.md).

## Highlights

v6.0.2 fixes `--update` wiping task ledger history in `docs/tasks/`.

### Installer

- **`merge-task-docs.py`** — on update, seed missing `docs/tasks/*.md` files or
  merge ledger format without overwriting listed tasks
- **`install.sh`** — update copies non-task `docs/` subtrees separately so task
  ledgers are handled by the merge helper

### Tests

- `tests/functional/test_merge_task_docs.py` — ledger merge and seed behavior
- `tests/functional/test_install_script.py` — update preserves task rows
