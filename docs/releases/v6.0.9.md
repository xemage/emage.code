- **Canonical orchestrator policy updated**: the rule was added to `implementation/knowledge/agents/orchestrator.md` and synchronized to all platform projections.
- **Contributor/runtime docs updated**: `README.md` and `CONTRIBUTING.md` now explicitly document the notes-file source-of-truth release command.
- **Registry refreshed**: regenerated registry artifacts to satisfy validation-gate drift checks after knowledge/doc updates.
