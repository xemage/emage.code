# Release v6.0.0

## Install

Latest release: v6.0.0

**Recommended:** use the installer from a clone of this repository:

```bash
git clone https://gitlab.com/em-age/emage.code.git
cd emage.code
scripts/install.sh --target <your-project> --platform cursor
```

| Platform | `--platform` value |
|----------|-------------------|
| Cursor | `cursor` |
| GitHub Copilot (VS Code) | `github` |
| Gemini CLI | `gemini` |
| Opencode | `opencode` |
| Pi | `pi` |
| All platforms | `all` |

Makefile shortcut: `make install TARGET=<your-project> PLATFORM=cursor`

Configure MCP credentials from the generated platform config, then invoke:

```
/discover-skills "start new project"
/new-project "My SaaS application"
```

Full guide: [`implementation/README.md`](../../implementation/README.md)
and [Quick Start](../wiki/quick-start.md).

## Highlights

v6.0.0 simplifies the repository to a **single implementation stream** with no
historical version trees or migration documentation.

### Repository cleanup (breaking)

- Removed `archive/` and all multi-version layout documentation
- Renamed tooling: `sync.mjs`, `verify.mjs`, `check.py`, `generate-registry.py`, `package.py`
- Updated CI, tests, wiki, and release docs for the unified layout

### Documentation

- Rewrote `README.md`, `CONTRIBUTING.md`, and wiki pages for single-stream workflow
- Release docs gate updated for new script names and content requirements

## Breaking changes

- **Scripts:** use `check.py`, `sync.mjs`, `verify.mjs` (no `-v3` suffix)
- **Validation:** `--root implementation` from repository root
- **No archive:** historical version trees are no longer shipped in this repository
