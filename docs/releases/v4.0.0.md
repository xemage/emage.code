# Release v4.0.0

## Install

Latest release: v4.0.0

**v4 builds on the v3 schema-first stream.** Copy the platform folder for your
assistant plus shared workspace files from `v3/implementation/`:

```bash
# GitHub Copilot (VS Code)
cp -r v3/implementation/.github         <your-project>/
mkdir -p <your-project>/.vscode
cp    v3/implementation/.vscode/mcp.json <your-project>/.vscode/

# Gemini CLI
cp -r v3/implementation/.gemini         <your-project>/

# Opencode
cp -r v3/implementation/.opencode       <your-project>/

# Cursor
cp -r v3/implementation/.cursor         <your-project>/

# Pi (terminal coding agent — https://pi.dev)
cp -r v3/implementation/.pi             <your-project>/.pi/

# Always include
cp    v3/implementation/AGENTS.md       <your-project>/
cp -r v3/implementation/docs            <your-project>/
```

Configure MCP credentials (`GITLAB_PERSONAL_ACCESS_TOKEN`, `BRAVE_API_KEY`, …)
from the generated platform config, then invoke:

```
/discover-skills "start new project"
/new-project "My SaaS application"
```

Full guide: [`v3/implementation/README.md`](../../v3/implementation/README.md)
and [Quick Start](../wiki/quick-start.md).

## Highlights

v4.0.0 aligns emage.code with ecosystem best practices from Superpowers and
Awesome OpenCode while keeping the v3 schema-first architecture.

### Mandatory workflow skills (new)

- **`systematic-debugging`** — four-phase root cause before any fix
- **`receiving-code-review`** — rigorous response to review feedback
- **`verification-before-completion`** — evidence before done/commit/MR claims
- **`AGENTS.md` Skill Workflow** table — orchestrator-enforced skill checks

### Session continuity

- **`/handoff`** — structured session handoff using v3 handoff schema
- **`/discover-skills`** — registry-driven skill recommendations for current intent
- **Trigger recipes** — `handoff-resume`, `background-agent-delegate`

### Agent safety guards

- Destructive git/fs command blocks (CC Safety Net patterns)
- Secret file read blocks (`.env`, keys, credentials)
- Handoff payload rules integrated with `runtime/handoff/validator.py`

### Inventory (v4.0.0)

- 27 agents, **18 slash commands**, **25 skills**, 4 instruction sets
- 5 platform projections: GitHub Copilot, Gemini, Opencode, Cursor, Pi
- Cookbooks, triggers, packaging, registry, telemetry (v3 runtime unchanged)

### Inherited from v3

- Schema-first knowledge under `v3/implementation/knowledge/`
- `check-v3.py` + `verify-v3.mjs` validation super-gate
- Release docs contract (`docs/releases/vX.Y.Z.md`)

## Breaking changes

- **Mandatory skill workflow** — agents must consult applicable skills before
  implementation, debugging, review response, and completion claims (exceptions
  require orchestrator approval).
- **Agent safety guards** — destructive git/fs and secret-file reads are hard
  blocks unless the user explicitly approves in-session.
