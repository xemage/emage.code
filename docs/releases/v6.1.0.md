# v6.1.0

Latest release: v6.1.0

## Install

Choose your platform:

| Platform | Command |
|----------|---------|
| GitHub Copilot | `scripts/install.sh --target <dir> --platform github` |
| Cursor | `scripts/install.sh --target <dir> --platform cursor` |
| Gemini CLI | `scripts/install.sh --target <dir> --platform gemini` |
| Opencode | `scripts/install.sh --target <dir> --platform opencode` |
| Pi | `scripts/install.sh --target <dir> --platform pi` |
| All platforms | `scripts/install.sh --target <dir> --platform all` |

Update an existing install: add `--update` flag.

## Highlights

- **Git Workflow Enforcement**: Orchestrator now enforces branch routing policies (feat→feature/*, fix→bugfix/*, etc.), implementation guards preventing direct commits to develop/main, and mandatory MR approval workflows across all platforms.
- **Release Workflow Preflights**: Documentation gate requiring `docs/releases/vX.Y.Z.md` as source-of-truth, task sequencing validation, and blocking conditions (CI green, security gate pass, task completion tracking).
- **Multi-platform synchronization**: Workflow enforcement policies are now synchronized across all 5 AI assistant platforms (GitHub Copilot, Cursor, Gemini, Opencode, Pi) from a single canonical knowledge source.
- **Enhanced task and settings management**: Updated task ledger with workflow enhancements and per-platform VS Code settings configuration.

## Breaking changes

None.
