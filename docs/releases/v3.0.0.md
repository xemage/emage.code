# Release v3.0.0

## Install

Latest release: v3.0.0

**v3 is the current release stream.** Copy the platform folder for your assistant
plus shared workspace files from `v3/implementation/`:

```bash
# GitHub Copilot (VS Code)
cp -r v3/implementation/.github         <your-project>/
mkdir -p <your-project>/.vscode
cp    v3/implementation/.vscode/mcp.json <your-project>/.vscode/

# Gemini CLI
cp -r v3/implementation/.gemini         <your-project>/

# Opencode
cp -r v3/implementation/.opencode       <your-project>/

# Cursor
cp -r v3/implementation/.cursor         <your-project>/

# Pi (terminal coding agent — https://pi.dev)
cp -r v3/implementation/.pi             <your-project>/.pi/

# Always include
cp    v3/implementation/AGENTS.md       <your-project>/
cp -r v3/implementation/docs            <your-project>/
```

Configure MCP credentials (`GITLAB_PERSONAL_ACCESS_TOKEN`, `BRAVE_API_KEY`, …)
from the generated platform config, then invoke:

```
/new-project "My SaaS application"
```

Full guide: [`v3/implementation/README.md`](../../v3/implementation/README.md)
and [Quick Start](../wiki/quick-start.md).

## Highlights

v3.0.0 promotes the schema-first implementation stream to the **current release**.
It keeps the same 27-agent permission model and adds stronger validation,
packaging, and runtime workflows.

### Drop-in multi-platform projection

- Single canonical knowledge tree under `v3/implementation/knowledge/`
- Deterministic sync to **GitHub Copilot**, **Gemini CLI**, **Opencode**, **Cursor**, and **Pi**
- `AGENTS.md`, task ledger, checkpoints, ADRs, and MCP registry included
- 16 slash commands, 22 skills, 4 always-on instruction sets

### Schema-first runtime (v3-only)

- **Cookbooks** — managed orchestrator-worker manifests (`cookbooks/`)
- **Triggers** — schedule/event runner with policy guardrails (`runtime/triggers/`)
- **Packaging** — install / update / uninstall knowledge packs (`package-v3.py`)
- **Registry** — machine-readable agent/skill/command index
- **Adapters** — experimental SDK smoke tests (Antigravity, Opencode)
- **Telemetry & replay** — trajectory capture and comparison gates

### Validation super-gate

- `check-v3.py` — 235+ checks (schemas, cookbooks, handoff security, hooks, benchmarks, registry, packaging, triggers, adapters)
- `verify-v3.mjs` — projection drift detection across all platform outputs
- CI gates: `v3-super-gate`, `verify-v3-knowledge-drift`, `sync-v3-no-diff`

### Release & documentation

- Release docs gate requires `Latest release: vX.Y.Z` markers and per-release
  highlights in `docs/releases/vX.Y.Z.md`
- Wiki and README aligned to v3 install paths
- v2 preserved as previous stable stream; v1 frozen

## Breaking changes

- **Default install path moves to `v3/implementation/`** (was `v2/implementation/`).
  v2 remains available for existing deployments.
- Release notes now require `docs/releases/vX.Y.Z.md` with Install + Highlights
  sections before tagging.
