## Highlights

- **Per-generation cost/latency telemetry (T234)**: New `GenerationMetrics` dataclass and `GenerationBudgetMonitor` instrument the self-improvement loop with prompt/sampled token counts, proxy-added latency, sandbox runtime, and merge-ops per generation. A convergence/stop signal (token budget cap, generation cap, reward plateau) is derived automatically. No raw prompts or secrets are captured.
- **CWSO deployment guides**: Comprehensive deployment documentation for Docker Desktop (local dev), Proxmox LXC (on-premises), and Google Cloud Run (production). Includes automated setup scripts (`cwso-docker-desktop.sh`, `cwso-proxmox-setup.sh`), a central troubleshooting guide, and environment comparison matrix.
- **Git Workflow Enforcement (v6.1.0)**: Orchestrator enforces branch routing policies (feat→feature/*, fix→bugfix/*, etc.), implementation guards preventing direct commits to develop/main, and mandatory MR approval workflows across all platforms.
- **Release Workflow Preflights (v6.1.0)**: Documentation gate requiring `docs/releases/vX.Y.Z.md` as source-of-truth, task sequencing validation, and blocking conditions (CI green, security gate pass, task completion tracking).
- **Fine-tuned model production deployment (T240/T241)**: v1-ft model deployed to production rollout path with 24-hour post-deployment monitoring (zero regressions, P95 latency 486 ms, error rate 0%).
- **SIA closed-loop evaluation (T233)**: Closed-loop eval on held-out tasks confirmed promotion decision APPROVED with no benchmark regressions.
- **Flaky test fix**: `_query_signatures` unit tests now dispatch mock responses by `target_symbol` kwarg rather than iteration order, eliminating set-ordering flakiness.
