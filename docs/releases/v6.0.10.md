# v6.0.10

Latest release: v6.0.10

## Install

Choose your platform:

| Platform | Command |
|----------|---------|
| GitHub Copilot | `scripts/install.sh --target <dir> --platform github` |
| Cursor | `scripts/install.sh --target <dir> --platform cursor` |
| Gemini CLI | `scripts/install.sh --target <dir> --platform gemini` |
| Opencode | `scripts/install.sh --target <dir> --platform opencode` |
| Pi | `scripts/install.sh --target <dir> --platform pi` |
| All platforms | `scripts/install.sh --target <dir> --platform all` |

Update an existing install: add `--update` flag.

## Highlights

- **Installer --update now preserves curated docs**: `install.sh --target <repo-root> --platform all --update` now merges template files without overwriting existing project documentation (e.g., docs/wiki/README.md, docs/wiki/home.md). Uses rsync --ignore-existing with fallback to cp -rn for maximum compatibility.
- **Self-target updates supported safely**: projects can now safely update in-place with --update mode; existing docs are always preserved and new templates are added only where missing.
- **Path resolution portable**: installer uses python3-based path resolution first (maximum portability) with fallback to realpath for edge cases.

## Breaking changes

None.
