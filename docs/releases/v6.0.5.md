# Release v6.0.5

## Install

Latest release: v6.0.5

**Recommended:** use the installer from a clone of this repository:

```bash
git clone https://gitlab.com/em-age/emage.code.git
cd emage.code
scripts/install.sh --target <your-project> --platform cursor
```

| Platform | `--platform` value |
|----------|-------------------|
| Cursor | `cursor` |
| GitHub Copilot (VS Code) | `github` |
| Gemini CLI | `gemini` |
| Opencode | `opencode` |
| Pi | `pi` |
| All platforms | `all` |

Makefile shortcut: `make install TARGET=<your-project> PLATFORM=cursor`

**Update an existing project** (requires `AGENTS.md` in the target):

```bash
scripts/install.sh --target <your-project> --platform github --update
```

Configure MCP credentials from the generated platform config, then invoke:

```
/discover-skills "start new project"
/new-project "My SaaS application"
```

Full guide: [`implementation/README.md`](../../implementation/README.md)
and [Quick Start](../wiki/quick-start.md).

## Highlights

v6.0.5 fixes GitHub Copilot / VS Code specialist agent delegation for installed
projects.

### Bug fixes

- **GitHub Copilot subagent aliases** — stop projecting display `name` into
  `.github/agents/*.agent.md` so Copilot registers agents by filename slug
  (e.g. `product-owner`), matching orchestrator `agents:` lists and fixing
  *"The named specialist alias is not registered in this workspace"*.
- **Sync engine** — parse YAML boolean literals (`true`/`false`) correctly when
  projecting `user-invocable` for GitHub agents.
- **Regression tests** — add GitHub projection checks for slug aliases and
  orchestrator delegation lists.
