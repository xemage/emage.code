## `/batch` is deliberately NOT promoted

Measured, not assumed. All five wave-2 commands were flipped to `stable` together first:

```
FAIL command/batch claims stable:
  - experimental->beta #3 (no open P0 defect): golden case batch-manifest-ledger-schema-conflict
    is a known_failing tracked_defect for /batch
  - beta->stable #7 (no open P0 or P1 defect): ... same case
```

The other four passed clean. **The honest red case blocked exactly the one component it should, and
nothing else** — the second consecutive wave where that held, after `T525`/`T526`'s `/skillify`.

It is the strongest available evidence wave 2's four greens were earned rather than manufactured:
**the same authoring pass that earned four promotions also cost one.** An implementer optimising for
a green board would not have produced that distribution twice.

`/batch` promotes only once the step-5-manifest-versus-ledger-schema conflict is adjudicated under
`ADR-007`. That is separate work and is **not** attempted here.
