## Objective

CWSO is a deployed, tested runtime dependency (Docker stack via `deploy/docker-compose-t226.yml`, JWT minting
via `CwsoClient.from_env()`, live contract test passing, 11 MCP tools confirmed) but no part of emage.code's
agent-facing knowledge base currently mentions it. Confirmed: `grep -rl -i cwso .claude/skills .claude/agents
implementation/knowledge` returns zero hits. Author a new skill that gives agents awareness of CWSO's
existence, purpose, and — critically — the mandatory worker/orchestrator permission split enforced by the
live CWSO server (undocumented server-side, discovered empirically in task T214; a client using the wrong
role for a tool call gets HTTP 403). Then wire that awareness into the three agent knowledge files whose
CWSO permission tier (per `role-mapping-cwso-v1.md`) is not `read`.
