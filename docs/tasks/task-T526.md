## Objective

## `/skillify` is deliberately NOT promoted

`T525` authored four cases. Three are `expected_pass`; the fourth,
`skillify-skill-file-template-drift`, is `known_failing` / `tracked_defect` because the `/skillify`
command and the `skillify` skill declare two incompatible `SKILL.md` templates and **0 of 26 real
skill files satisfy the command's**.

Measured, not assumed — all four were flipped to `stable` together first:

```
FAIL command/skillify claims stable:
  - experimental->beta #3 (no open P0 defect): golden case skillify-skill-file-template-drift
    is a known_failing tracked_defect for /skillify
  - beta->stable #7 (no open P0 or P1 defect): ... same case
```

**This is the ladder working exactly as designed.** An honestly-authored red case blocked precisely
the one component it should, and nothing else. It is the strongest available evidence that wave 1's
three greens were earned rather than manufactured: the same authoring pass that produced them also
produced a case that costs a promotion.

`/skillify` promotes only once the contract conflict is adjudicated under `ADR-007`. That is a
separate task and is **not** attempted here.
