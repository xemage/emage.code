# Task T031 — Audit v3 documentation gaps

## Objective
Audit the current repository and wiki documentation against the v3 implementation so the exact missing or incorrect user-facing guidance is identified before edits are made.

## Inputs
- `README.md`
- `CONTRIBUTING.md`
- `docs/wiki/*.md`
- `v3/implementation/README.md`
- `v3/implementation/scripts/*.mjs`
- `v3/implementation/scripts/check-v3.py`

## Expected outputs
- audit artifact listing v3 doc gaps and command inaccuracies
- implementation recommendations for T032-T035

## Acceptance criteria
- Document the v3 usage path, doc omissions, and any incorrect command examples.
- Identify the minimum docs and code changes needed to make v3 usable by a new contributor.

## Blocker protocol
If blocked, report blocker type and severity with one proposed mitigation.
