# MCP Servers

emage.code uses [Model Context Protocol](https://modelcontextprotocol.io) servers as the integration layer between agents and external tools.

All servers are declared once in [`v3/implementation/knowledge/mcp/servers.yaml`](https://gitlab.com/em-age/emage.code/-/blob/main/v3/implementation/knowledge/mcp/servers.yaml) and projected to platform-specific config files.

## Tag system

| Tag | Behaviour |
|-----|-----------|
| `core` | Emitted to **every** platform, always available |
| `extended` | Emitted only to platforms that opt in via their manifest (`gemini`, `opencode`, `cursor`) |

## Core servers (always available)

| Server | Purpose | Used by |
|--------|---------|---------|
| `gitlab` | Repository, issues, MRs, pipelines | Orchestrator, Scrum Master, DevOps, Release Manager |
| `playwright` | Browser automation, E2E testing | QA, Frontend, Demo Agent |
| `memory` | Persistent knowledge graph | Orchestrator (team memory) |
| `sequential-thinking` | Complex problem decomposition | Architect, Orchestrator |
| `fetch` | Web content fetching | Architect, Tech Lead, Developers |
| `brave` | Technology discovery (web search) | Technology Scout, Feasibility |
| `context7` | Framework / API documentation lookup | Technology Scout, Integration |

## Extended servers (opt-in)

`hf-mcp-server`, `filesystem`, `github`, `git`, `supabase`, `e2b`, `docker`, `redis`, `postgresql`, `figma`, `notion`, `toolradar`.

Most require additional credentials — see [`servers.yaml`](https://gitlab.com/em-age/emage.code/-/blob/main/v2/implementation/knowledge/mcp/servers.yaml) for the full env-var contract.

## Required environment variables

| Variable | Server | Notes |
|----------|--------|-------|
| `GITLAB_PERSONAL_ACCESS_TOKEN` | `gitlab` | Scopes: `api`, `read_repository`, `write_repository` |
| `BRAVE_API_KEY` | `brave` | Free tier: 2000 queries/month |
| `GITHUB_TOKEN` | `github` (extended) | Classic PAT or fine-grained |
| `SUPABASE_ACCESS_TOKEN` | `supabase` (extended) | Project access token |
| `FIGMA_ACCESS_TOKEN` | `figma` (extended) | Personal access token |
| `NOTION_API_KEY` | `notion` (extended) | Internal integration token |

> **Never commit these.** Use environment variables or a secret vault. See [`SECURITY.md`](https://gitlab.com/em-age/emage.code/-/blob/main/v2/implementation/SECURITY.md) for the full rules.

## Per-platform output

| Platform | Output file |
|----------|-------------|
| GitHub Copilot | `.vscode/mcp.json` |
| Gemini CLI | `.gemini/settings.json` |
| Opencode | `opencode.json` |
| Cursor | `.cursor/mcp.json` |

All four are regenerated by `node v2/implementation/scripts/sync.mjs`.
